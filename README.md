# РАДАР — академия радиолокации

Русскоязычный учебный сайт: от первого эха до когерентной обработки и сопровождения. Материал объясняет физический смысл; вычислительных упражнений нет.

- 12 уроков: начальный, средний и продвинутый уровни.
- 48 вопросов с разбором ответов, повторными попытками и зачётом от 3 из 4.
- Лаборатория: обзор, импульс/эхо и Доплер, перемещение объекта и пауза.
- Глоссарий, поиск, избранное, прогресс и пять тёмных тем.
- Адаптация для телефона, навигация с клавиатуры, поддержка уменьшения анимации.

## Запуск

Требуется Node.js 22.12+ или 24 LTS и npm. Проверено с Node.js 24.19.0.

```bash
cd /workspace/GPTpj1
npm ci --cache /tmp/radar-npm-cache
npm run dev -- --port 4173 --strictPort
```

Для обычного локального клона используй путь к своей папке вместо `/workspace/GPTpj1`. Кэш в `/tmp` нужен в облачной среде, где домашняя папка недоступна для записи. Дополнительных ключей, базы данных и регистрации нет.

## Сборка

```bash
npm run build
npm run preview -- --port 4173 --strictPort
```

Папка `dist/` — готовый статический сайт. Её можно разместить на статическом хостинге. В облачной среде процессы после восстановления снимка нужно запустить снова. Создание файлов и сборка сами по себе не публикуют сайт в интернете и не отправляют изменения на GitHub.

## Проверка

```bash
npm test
```

В облаке используется Chromium из `/usr/bin/chromium`. На другом компьютере задай путь через `CHROMIUM_PATH` или установи браузер для Playwright и измени `executablePath` в конфигурации. Проверки проходят по настоящим пользовательским сценариям: чтение и тест, ошибки и повтор, сохранение прогресса, поиск, избранное, темы, лаборатория и мобильная навигация.

## Где что менять

- `src/data/curriculum.js` — тексты уроков, вопросы, объяснения и источники.
- `src/App.jsx` — страницы и логика обучения.
- `src/components/RadarLab.jsx` — учебная визуализация.
- `src/styles.css` — оформление и темы.
- `docs/SOURCES.md` — проверка содержания и ограничения источников.

Прогресс, избранное и оформление хранятся в `localStorage` этого браузера. Синхронизации между устройствами нет. При недоступном хранилище можно продолжать учиться, но сохранение между посещениями не гарантируется.

Лаборатория — условная иллюстрация принципов. Скорости, яркость и геометрические масштабы не воспроизводят характеристики реальных станций.
