# Сверка учебных материалов

Дата проверки: 22 октября 2026 года. Учебные тексты написаны самостоятельно; код, иллюстрации и тексты источников в приложение не перенесены.

## Что действительно прочитано

В текущей среде разрешён доступ к GitHub. Для проверки были прочитаны исходные Markdown-ячейки учебных ноутбуков и соответствующие формулы/функции двух публичных репозиториев. Примеры не исполнялись: это проверка содержания, а не проверка программ-симуляторов.

1. [Andy Harrison, Introduction to Radar Using Python and MATLAB — companion materials](https://github.com/RadarBook/software/tree/a39727875196a1a1ec56cda38a488315fb4800b4). Из README и заголовков материалов установлены название, Artech House, 2019 год и ISBN 9781630815974. Проверенная ревизия: `a39727875196a1a1ec56cda38a488315fb4800b4`.
2. [RadarSimX — учебные примеры RadarSimPy](https://github.com/radarsimx/radarsimnb/tree/23ec2b7a9ff45c9faa9fb21ef17fccf7841d8786). Прочитаны вводные объяснения CW, FMCW, импульсного Доплера, микродоплера и многоканального определения направления. Проверенная ревизия: `23ec2b7a9ff45c9faa9fb21ef17fccf7841d8786`. Это дополнительный учебный источник разработчика симулятора, а не стандарт или независимое подтверждение характеристик реальных РЛС. Численные параметры демонстраций не перенесены в курс; отдельные численные аннотации в этих примерах внутренне противоречивы.
3. [MIT OpenCourseWare — метаданные курса RES.LL-001](https://github.com/mitocwcontent/res.ll-001-spring-2007/blob/6adcd26faecdece52d6b8f5c3a22bd5444404588/data/course.json). Прочитаны название Introduction to Radar Systems, принадлежность MIT Lincoln Laboratory, Spring 2007 и описание десяти лекций. В этом репозитории нет конспектов или расшифровок лекций. Поэтому наличие ссылки на курс MIT не выдаётся за фактическую сверку учебных утверждений по лекциям MIT.
